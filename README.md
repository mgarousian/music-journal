# ژورنال موسیقی

یک وبلاگ ساده برای ثبت ایده‌های موسیقی. هر ایده یک فایل Markdown است که نت آن به فرمت متنی ABC نوشته شده و در صفحه به‌صورت نت‌نویسی استاندارد، با دکمه‌ی پخش، نمایش داده می‌شود.

ساخته‌شده با [Astro](https://astro.build) و [abcjs](https://www.abcjs.net)، میزبانی روی GitHub Pages.

## ساختار پروژه

```
src/content/ideas/       ← هر ایده یک فایل .md
public/photos/           ← عکس دست‌نویس‌های اصلی
src/components/Idea.astro← شکل نمایش یک ایده
src/pages/index.astro    ← صفحه‌ی اصلی (همه‌ی ایده‌ها، جدیدترین بالا)
src/pages/ideas/[id].astro ← صفحه‌ی جدای هر ایده
public/notation.js       ← رسم نت و پخش با abcjs
public/style.css         ← ظاهر سایت
.github/workflows/deploy.yml ← بیلد و انتشار خودکار
```

## شکل یک ایده

```markdown
---
title: عنوان ایده
date: 2026-11-09T13:40:00+03:30
photo: photos/2026-11-09-1340.jpg
abc: |
  X:1
  L:1/8
  M:6/8
  Q:1/8=120
  %%MIDI program 15
  K:C _B _/E _A
  G A B A G F | E2 F G3 |]
---

متن آزاد: دستگاه، کوک ساز، حس و حال، هر چیزی.
```

- `date`: تاریخ و ساعت ثبت. سایت آن را به تقویم شمسی و وقت تهران نشان می‌دهد.
- `photo`: اختیاری؛ مسیر عکس داخل پوشه‌ی `public`.
- `abc`: اختیاری؛ نت به فرمت ABC.
  - `K:C _B _/E _A` یعنی سی بمل، می کرن (`_/` = نیم‌بمل)، لا بمل. برای سری از `^/` استفاده می‌شود.
  - `%%MIDI program 15` صدای پخش را شبیه سنتور (دالسیمر) می‌کند. بدون آن، پیانو پخش می‌شود.

## راه‌اندازی اولیه روی گیت‌هاب (فقط یک بار)

۱. در ریپو: **Settings → Pages → Build and deployment → Source** را روی **GitHub Actions** بگذارید.
۲. از این به بعد هر تغییری که به شاخه‌ی `main` برسد، ظرف یکی دو دقیقه روی سایت می‌آید.
آدرس سایت: `https://<نام‌کاربری>.github.io/<نام‌ریپو>/`

## اجرای لوکال (اختیاری)

```bash
npm install
npm run dev
```

بعد `http://localhost:4321` را باز کنید.
